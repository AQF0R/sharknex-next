# Pi 控制台简单测试入口

## 设计预检
2026-11-15，仅修改 web，不修改 Go、数据库或服务 API。
模式判断：不新增 GoF 类层级，现有创建抽屉的显式分支与独立展示组件已足够。复用 API/Pinia 与 bounded events，不引入第二条轮询。
目标数组使用 Set 去重 O(N)；Pi 简单入口仅接受一个完整精确 HTTP/HTTPS URL。用 Map 按 task_id + generation 保存最新累计 usage，O(E) 时间/空间；E 由现有最多 500 条已加载事件限制。不将每条累计用量直接相加。
状态：local 与 Pi 各自保留目标草稿；失败保留草稿并显示持久错误；提交期间防重、禁用编辑与关闭。模式提示使用短过渡，支持 reduced-motion；抽屉和 Tabs 使用现有组件库动效。
安全：模型密钥只在服务端配置，页面不读取或保存；响应作为文本渲染，无 v-html。目标仅是授权声明，真正权限由后端校验。
验证：现有 lint/type-check/build；浏览器检查模式、警告、提交拒绝和草稿；无外部模型成功验收。

## 使用
1. 打开 http://127.0.0.1:5174，创建运行，选择 Pi 只读测试。
2. 填写完整授权 URL，点击创建并启动。
3. 模型须预先在服务端设置 PI_ENABLED、PI_MODEL、PI_BASE_URL、PI_API_KEY 并重启；本地靶场需 PI_ALLOWED_CIDRS。
4. 在 Pi 执行页签查看受限审计；共享知识查看 HTTP 观察；任务详情查看执行器、事件载荷和证据索引。
5. 本阶段只读 HTTP 观察不是漏洞确认。显示的 Token 合计仅覆盖已加载事件，并非完整计费账单。
