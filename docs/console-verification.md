## 当前边界
- 实时传输是每秒 HTTP 增量轮询，不是浏览器 WebSocket。
- 协作图使用全宽纵向角色舞台并聚焦当前任务，Planner 位于顶层，Worker 位于 Scheduler 下层；完整任务由下方队列承载。初始适配等待节点测量完成并居中展示全局，不声称通过千节点性能压测。
- 当前快照会重读完整结果及事件；事件窗口最近 500 条、筛选显示最多 80 条，建议和证据索引最多 200 条，导航最近 100 个运行。大历史分页和服务端轻量快照留待后续。
- 按需注册组件后 JS 从约 1.85 MB 降为约 1.28 MB（gzip 约 400 KB），构建仍有大 chunk 提示，未将警告屏蔽。
- 当前环境 Node 25.9 的部分生成器开发依赖会报告 engine 支持范围警告；本次实际检查通过，README 推荐 Node 24 LTS 24.15+。
- 普通新功能没有新增永久测试源码；行为验证采用真实浏览器、HTTP 和数据库。静态构建入口需要用户在内存中输入控制令牌，开发自动连接只在 5174 同源代理可用。
