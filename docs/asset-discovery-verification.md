# 资产发现阶段验收

2026-11-15。本阶段交付单IP资产/端口/有限服务指纹及结构化报告，不宣称已完成完整Web漏洞基线、候选Finding独立验证或攻击利用能力。

## 实现
- Scope.tcp_ports + authorization.confirmed/statement 与 Run 一起保存。Task.ports 必须属于声明端口且无重复，最多16个。控制API凭证代表声明发起者，网络任务同Run内不再次询问授权，截止时间仍由Engine强制执行。模型只接收经过控制端验证的任务，不可改IP或端口。
- tcp.discover / Pi discover_services：全局共享一个探测槽，串行TCP connect，至少500ms间隔，800ms连接超时，28秒扫描阶段时间上限，Runtime原45秒总时限不变。
- 欢迎banner和HTTP指纹有界，HTTP仅授权端口根路径，不跟随Location或代理、无Cookie、TLS正常验证，不执行页面内容。端口提示和实测协议明确分开。
- 结构化事实与证据，存在开放端口时保存主机资产；新资产报告页提供覆盖率、端口状态、指纹依据、失败限制、声明记录。不是以模型摘要生成结果。
- 表单草稿保留，服务端错误可见；目标/端口/声明改变时撤销勾选。沿用Ant Design Vue与现有过渡，报告空态到数据用短过渡并支持reduced-motion。
