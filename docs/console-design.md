# 实时协作控制台

## 范围
Vue 3、TypeScript、Ant Design Vue。采用深色导航 + 浅色工作画布，非聊天界面；主路径为运行选择 → 动态任务图 → 节点详情 → 事实与结果。浏览器真正可执行创建、启动、取消和结果导出。

## 设计预检
- 采用 Adapter：类型化 API service 隔离传输；Pinia 保存运行数据，Vue Flow 负责缩放、拖动和节点渲染。主视图使用全宽协作舞台，不加载右侧事件流或重复 Worker 卡片区。
- 实时使用每秒游标增量 HTTP 事件同步，后台快照仅在有事件或用户操作时刷新；当前不把轮询标为 WebSocket。重连从最后成功 sequence 补齐，暂停时冻结视图，恢复补齐。网络错误保持现有数据并明确显示。
- 使用 Map 按实体 ID 保存位置；按 Planner → Scheduler → Worker → 当前任务 → Blackboard 纵向排列，Worker 在独立层横向展开，完整任务由下方队列承载。角色以低饱和边框色和轻微圆角差异区分，不使用装饰性炫光。
- Worker 名称区域使用“执行者 A/B/C”等可读角色名，自定义名称保持原样；显示当前或最近任务，并展示该 Worker 已完成/已分配任务进度及当前协作阶段。进度只根据真实分配任务计算，不使用全局任务进度替代。
- 图节点以 ID 为 key，实时刷新保留已有拖动位置、缩放和选择；当前任务随最新真实任务事件切换。首次适配等待节点测量完成并居中展示全局，最大初始倍率 0.96；手动整理阵容明确作为用户动作。
- 运行、标签页通过 Router Query 保存，筛选和分页在页面组件内保留；认证与令牌只放内存。创建抽屉关闭保留草稿，有未保存内容需确认；异步请求通过 AbortController 与代数丢弃旧响应。
- 任务创建来自 Planner、分配与解锁来自 Scheduler、事实写入 Blackboard，执行交接来自真实 Worker。移动角色使用带方向和角色道具的小人；交接期间显示与运动关键帧一致的临时二次曲线，结束后消失，不使用静态传统连线。初次载入和暂停期间不补播历史；同一时刻最多 1 个交接，新事件不打断当前动画，也不排队补播被省略的视觉事件。Worker 仅在真实忙碌时做轻微动作。角色层跟随视口变换并抵消缩放，支持 reduced-motion，当前事件和任务队列始终提供非动画信息。
- UI 文案明确“本地受控演示”，不会把规则执行器称为真实 LLM/漏洞扫描。
- 验证：ESLint、vue-tsc、生产构建、Go vet/build；真实浏览器验证创建/启动/取消、节点详情、动态任务与事件、重连及窄屏布局。普通新功能不新增测试源码。

## dev 安全与入口
Vite 仅绑定 127.0.0.1:5174，使用同源反向代理访问 Go 的 8080。代理在服务端加载根 .env，注入 Bearer；绝不通过 VITE_ 变量或前端源码暴露令牌。代理拒绝跨站 Origin、非本机 Host 和 cross-site 请求。此自动连接仅用于本地开发，生产构建使用内存令牌登录，后端权限校验始终保留。
后端根路径提供已构建静态控制台；Vite dev 提供热更新控制台。make dev 一次启动二者，检查已有健康的 dev 后端时可复用，不杀死未知进程。生产静态托管只服务明确的 assets 和 index，不将 API 404 改为首页。
